# 프로젝트 소개

## ⚡️ 번개처럼 빠르게! 새로운 사람들과 만나보세요
번개팅은 누구나 빠르고 간편하게 모임을 생성하고 참여할 수 있는 번개 모임 플랫폼입니다 <br/>
실제 참여자들의 신뢰도 높은 후기를 통해 안심하고 만남을 가질 수 있으며, 실시간 채팅 기능으로 원활한 소통이 가능합니다.  <br/>
새로운 사람들과 색다른 경험을 해보고 싶을 때, 번개팅과 함께해보세요! <br/>

## 🎯 프로젝트 목표
* 사용자들이 빠르게 원하는 모임을 찾고 참여할 수 있도록 직관적인 UI 제공 <br/>
* 실시간 채팅을 통해 원활한 소통 제공 <br/>
* 실제 참여자들의 신뢰할 수 있는 솔직한 후기 시스템 구축 <br/>
* PWA(Progressive Web App) 적용을 통해 웹에서도 앱처럼 원활하게 이용 가능 <br/>
* JWT 인증 방식을 도입하여 안전한 로그인 및 회원 관리 <br/>

# 주요 기능

### 1️⃣ 모임 기능
* **모임 조회:** 다양한 카테고리(술자리, 보드게임, 카페, 맛집 등)의 번개 모임을 한눈에 확인 가능 <br/>
* **모임 생성:** 누구나 쉽게 모달을 통해 원하는 번개 모임을 생성 <br/>
* **모임 참여:** 지역 및 관심사 기반으로 원하는 테마의 번개 모임에 참여 가능 <br/>
* **모임 상세보기:** 주최자 정보, 상세 내용, 위치 정보, 참가자 리뷰 확인 가능 <br/>
* **찜 기능:** 마음에 드는 모임을 찜 해둘 수 있음 <br/>

### 2️⃣ 리뷰 시스템
* **실제 참여자만 리뷰 가능:** 신뢰할 수 있는 후기 제공 <br/>
* **별점 & 코멘트 작성:** 모임에 대한 피드백을 남길 수 있음

### 3️⃣ 마이 페이지
* 내가 만든 모임 & 참여한 모임 관리 <br/>
* 참여 내역 및 후기 관리 <br/>
* 프로필 수정: 닉네임, 프로필 사진, 소개글 변경 가능 <br/>

### 4️⃣ 실시간 채팅
* 참가자 간 일정 조율 및 정보 공유 가능 <br/>
* 모임 시작 전, 빠르게 소통 가능 <br/>

### 5️⃣ 유저관리
* 회원가입과 로그인을 통해 나만의 모임 관리 가능 <br/> 
* **게스트로그인:** 회원가입없이도 번개팅 사이트를 체험해볼 수 있음
